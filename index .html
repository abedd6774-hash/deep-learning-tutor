UNIT I

Tensor Operations and Computational Foundations

Goal: understand how data is represented, transformed and differentiated inside a neural network.

A simplified learning computation: tensors flow forward; gradients flow backward.

1. Tensor Operations and Tensor Manipulation Core

Simple meaning: A tensor is a container of numerical values arranged across zero or more dimensions. A scalar is 0-D, a vector 1-D, a matrix 2-D, and higher-dimensional arrays are also tensors.

Example: A grayscale image can be represented as height × width; a colour image often has height × width × channels; a batch adds another dimension.

scalar: 7
vector: [2, 4, 6]
matrix: [[1, 2], [3, 4]]
shape(image batch): (batch, height, width, channels)

Manipulation: inspect shape and rank, index/slice values, reshape without changing the element count, transpose axes, and use broadcasting for compatible shapes.

Why it matters: Shape mistakes are among the most common sources of deep-learning bugs. Always ask: what does each axis represent?

Try: A tensor has shape (32, 28, 28, 1). It represents 32 grayscale images, each 28 × 28 pixels, with one channel.

2. Vectorized Computation

Simple meaning: Perform an operation on a whole array at once rather than writing a Python loop for each element.

Loop idea: for each i, y[i] = x[i] * 2
Vectorized: y = x * 2

Array libraries execute these operations in optimised native code and can use hardware parallelism. Vectorization often makes code shorter and faster.

Example: For 1 million values, multiplying the entire NumPy array by 2 is preferable to a Python-level loop.

Remember: Vectorized does not mean every operation is automatically parallel on every device; the library and hardware determine execution.

3. Computational Graphs

Simple meaning: A computational graph represents a calculation as nodes (values or operations) connected by edges (data dependencies).

For y = wx + b, the forward pass evaluates the graph. Automatic differentiation traverses dependencies to calculate derivatives for the backward pass.

Why: It makes complex calculations differentiable and enables automatic gradient calculation.

4. Gradient Intuition and Backpropagation Fundamentals

Derivative intuition: A derivative tells how sensitive an output is to a small change in an input. A gradient collects partial derivatives for multiple variables.

If y = x², then dy/dx = 2x.
At x = 3, the slope is 6.

Backpropagation: First calculate prediction and loss (forward pass). Then use the chain rule from the loss backwards through the graph to find each parameter's contribution to the loss.

Chain rule: dL/dw = (dL/dy) × (dy/dw)

Important distinction: Backpropagation calculates gradients. Gradient descent or another optimizer uses those gradients to update parameters.

5. Optimization Concepts for Neural Networks

Simple meaning: Optimization adjusts model parameters to reduce a chosen loss function.

w(new) = w(old) − η × gradient(L with respect to w)

η is the learning rate. If it is too large, updates may overshoot; if too small, learning may be slow. Optimizers include SGD and adaptive methods such as Adam (additional context).

Training loop: predict → calculate loss → calculate gradients → update weights → repeat over batches and epochs.

6. Parallel Tensor Computation for AI Applications

Simple meaning: Many tensor calculations can be divided into independent pieces and executed concurrently, especially on GPUs.

CPUs are designed for versatile, low-latency tasks; GPUs contain many processing units suited to high-throughput numerical workloads. Batches and matrix operations help expose parallel work.

Applications: matrix multiplication, convolution, batch processing and neural-network training. CUDA is an NVIDIA platform for programming GPU computation; it is part of the industry case study later.

Neural Networks

1. The Biological Neuron

A biological neuron receives signals through dendrites, integrates them in the cell body and transmits a signal through its axon. The artificial neuron is a simplified mathematical inspiration, not a literal copy of biology.

Artificial version: inputs are multiplied by weights, added with a bias, then passed through an activation function.

z = Σ(wᵢxᵢ) + b ; output = f(z)
2. The Perceptron

A perceptron is a basic artificial neuron used for a linearly separable classification task. It calculates a weighted sum and applies a threshold decision.

ŷ = 1 if w·x + b ≥ 0, otherwise 0

It can learn a linear decision boundary. A single perceptron cannot solve non-linearly separable patterns such as XOR without additional structure.

3. Multilayer Feed Forward Networks

Information flows from input layers through one or more hidden layers to an output layer. “Feed forward” means there are no feedback loops in this architecture.

Input layer
→
Hidden layer 1
→
Hidden layer 2
→
Output layer

Weights and biases are trainable parameters. Hidden layers learn intermediate representations.

4. Word Embeddings and Distributed Representations

Word embeddings represent words as dense numerical vectors. Unlike one-hot vectors, learned embeddings can encode useful relationships and similarities.

Example intuition: words used in similar contexts may receive vectors that are close under a chosen similarity measure. An embedding is learned from data; it is not a hand-written dictionary of meanings.

Why in a neural-network unit? It is an example of a learned representation: the model learns useful numerical features instead of relying only on manually designed inputs.

5. Training Neural Networks

Training repeatedly exposes a model to examples and adjusts its parameters to reduce loss. An epoch is one pass through the training dataset; a batch is a subset processed for an update.

Training: batch → forward pass → loss → backpropagation → optimizer update

Training data fits the model; validation data helps monitor choices; test data estimates final performance on unseen examples.

6. Backpropagation Learning

Backpropagation applies the chain rule layer by layer, calculating gradients of the loss with respect to weights and biases. The optimizer then applies updates.

Common confusion: backpropagation is not the same as gradient descent. One computes gradients; the other uses them to change parameters.

8. Loss Function Notation and Losses

A loss function measures the mismatch between a model prediction and its target. Training seeks parameters that minimise the loss.

L(y, ŷ) = measure of error between target y and prediction ŷ
TypeExampleIntuition
RegressionMean Squared Error: (1/n)Σ(y−ŷ)²Penalises squared numerical errors.
ClassificationCross-entropyPenalises assigning low probability to the correct class.
ReconstructionMSE or binary cross-entropyCompares reconstructed input with original input.

Choose a loss that matches the task, output representation and target encoding.

9. Hyperparameters, Learning Rate, Regularization, Momentum and Sparsity

Parameters are learned from data (weights and biases). Hyperparameters are settings chosen by the practitioner (learning rate, batch size, number of layers, regularization strength).

Learning rate: controls update size. Regularization: discourages overly complex solutions, for example through weight penalties or dropout. Momentum: accumulates a moving direction from past gradients to smooth updates. Sparsity: encourages many activations or parameters to be zero or near zero, which can support compact representations.

UNIT III

Deep Networks

Goal: understand what makes a network deep, its reusable building blocks, and the major generative or unsupervised architectures named in your syllabus.

1. Deep Learning and Common Architectural Principles

Deep learning uses neural networks with multiple layers to learn representations at different levels of abstraction. Early layers may detect simple patterns; later layers can combine them into more complex features.

Architectures are built from layers and parameters, use activation functions to introduce nonlinearities, define losses to express objectives, and use optimization algorithms to learn parameters. Hyperparameters govern training and model design.

2. Parameters, Layers and Building Blocks of Deep Networks

A layer transforms an input representation into another. Parameters are the learned numbers inside the model. Common building blocks include linear/dense layers, convolutions, recurrent units, normalization, activations, pooling and skip connections (additional context).

Architecture question: What is the input shape? What transformation does each layer perform? What information is preserved or discarded? What is the output?

3. Restricted Boltzmann Machines (RBMs)

An RBM is a stochastic, energy-based neural network with visible and hidden units. Connections typically exist between visible and hidden layers, but not within the same layer. It can learn patterns in data and has been used for representation learning and pretraining.

Visible units
input pattern
⇄
Hidden units
learned features

Intuition: hidden units capture dependencies or features that help represent the observed data.

4. Autoencoders

An autoencoder learns to reconstruct its input. The encoder maps input to a compressed or transformed latent representation; the decoder maps that representation back to a reconstruction.

Input x
→
Encoder
→
Latent z
→
Decoder
→
Reconstruction x̂
Objective: minimise reconstruction loss L(x, x̂)

Applications include dimensionality reduction, denoising and anomaly detection (when appropriately designed and validated).

5. Variational Autoencoders (VAEs)

A VAE is a probabilistic generative model. Instead of encoding an input as one fixed latent point, its encoder predicts parameters of a latent distribution. A sample from that distribution is decoded to generate data.

Its objective balances reconstruction quality with a regularisation term that encourages the learned latent distribution to remain close to a prior distribution.

VAE objective (conceptual): reconstruction term + KL-divergence regularisation

Difference: a basic autoencoder focuses on reconstruction; a VAE structures a probabilistic latent space to support sampling and generation.

6. Unsupervised Pretrained Networks: Deep Belief Networks

A Deep Belief Network (DBN) is a generative model formed by stacking layers of latent variables, historically often trained using layer-wise unsupervised pretraining with RBMs.

Intuition: learn progressively more abstract representations, then use the learned features for a task or further training.

7. Generative Adversarial Networks (GANs)

A GAN trains two networks in competition: a generator creates synthetic samples; a discriminator tries to distinguish real samples from generated ones.

Random noise z
→
Generator
→
Fake sample
→
Discriminator

The discriminator also receives real examples. Their adversarial training encourages the generator to produce realistic samples.

Challenges include unstable training, mode collapse and evaluation of generated quality.

UNIT IV

Major Architectures of Deep Networks

Goal: select an architecture based on the structure of the input — spatial images, sequences over time, or hierarchical/structured data.

1. Convolutional Neural Networks (CNNs)

Intuition: CNNs use small learnable filters that scan across an image to detect local patterns. Early filters may respond to edges or textures; deeper layers combine them into more complex patterns.

Image input
→
Convolution
feature maps
→
Activation
→
Pooling
→
Dense layer
→
Prediction

Input layer: receives image tensor, often height × width × channels. Convolutional layer: applies filters to local regions. Pooling layer: downsamples feature maps, often retaining prominent responses. Fully connected layer: combines extracted features for a final prediction.

Biological inspiration: local receptive fields and hierarchical visual processing are analogies; CNNs are engineered mathematical systems, not biological replicas.

Applications: image classification, object detection, segmentation, medical imaging and visual inspection.

2. Recurrent Neural Networks: Modelling the Time Dimension

RNNs process sequences by carrying a hidden state from one time step to the next. This lets the model use information from earlier steps when processing later steps.

x₁
→
RNN cell
h₁
→
RNN cell
h₂
→
RNN cell
h₃

Each cell also receives the next input x₂, x₃, …; hidden state carries information forward.

Markov-model connection: a first-order Markov assumption says the next state depends on the current state. An RNN hidden state is a learned summary of past inputs, not the same thing as a classical Markov model.

3D volumetric input: a volume has three spatial dimensions (for example, depth × height × width in medical imaging). Do not confuse this with a time sequence; 3D CNNs and RNNs address different data structures, though hybrid approaches exist.

3. General Recurrent Neural Network Architecture

At each time step, the cell combines current input with previous hidden state to compute a new hidden state. The same parameters are reused across time steps.

hₜ = f(Wₓxₜ + Wₕhₜ₋₁ + b)

Basic RNNs can struggle to learn long-range dependencies because gradients may vanish or explode during backpropagation through time.

4. LSTM Networks

Long Short-Term Memory (LSTM) networks are recurrent networks designed to preserve and control information over longer sequences using a cell state and gates.

Forget gate: controls what information to discard. Input gate: controls what new information to store. Output gate: controls what information to expose as hidden state.

Previous cell state
→
Forget / input gates
→
Updated cell state
→
Output gate

Applications include sequence modelling, language, sensor signals and time-series tasks. Suitability depends on data and task; Transformers are also widely used for sequence modelling.

5. Domain-Specific Applications and Blended Networks

Different domains need different input representations. A video model may use CNN layers to extract frame-level visual features and a temporal model to learn how those features change across frames. This is one example of a blended architecture.

Other combinations can include CNN + RNN, feature extractor + classifier, or spatial + temporal processing. Choose components because they address a real property of the data.

6. Recursive Neural Networks: Architecture, Varieties and Applications

Recursive neural networks apply a shared composition function repeatedly over a hierarchical structure, such as a tree. They are useful when the input is naturally nested rather than a simple flat sequence.

word A
word B
↘ ↙
phrase representation
↑
combine with next phrase

Distinction: recurrent networks repeat over sequence time steps; recursive networks combine child representations according to a hierarchy. Applications include structured language representations and tree-structured data.

UNIT V

Autoencoders

Goal: understand how an encoder-decoder learns representations and how constraints change what it learns.

1. Undercomplete Autoencoders

An undercomplete autoencoder has a latent representation with fewer dimensions than the input. The bottleneck encourages the model to retain the most useful information for reconstruction.

Example: map 100 input features to 10 latent values, then reconstruct the 100 features. The model must learn a compact representation.

2. Regularized Autoencoders

Regularized autoencoders add constraints or penalties so the model does not simply learn an unhelpful identity mapping. Examples include sparsity penalties, denoising objectives and contractive penalties.

3. Representational Power, Layer Size and Depth

Representational power describes the patterns a model can express. Wider layers provide more units; deeper networks compose more transformations. More units or layers do not automatically mean better generalisation — data, optimization, regularization and task all matter.

4. Stochastic Encoders and Decoders

A stochastic encoder or decoder models distributions rather than only deterministic values. It can represent uncertainty and enable sampling. VAEs are an important example of this probabilistic approach.

5. Denoising Autoencoders

A denoising autoencoder receives a corrupted version of an input and learns to reconstruct the clean original. This encourages robust features rather than memorising exact input values.

Clean input x
→
Add noise
→
Encoder / decoder
→
Reconstructed x̂
6. Learning Manifolds with Autoencoders

A manifold is an intuitive way to describe data that may lie near a lower-dimensional structured surface inside a higher-dimensional space. Autoencoders can learn compact coordinates that capture some of this structure.

Example: although an image has thousands of pixel values, valid images of one object category may vary along a smaller number of meaningful factors such as position, lighting and orientation.

7. Contractive Autoencoders

A contractive autoencoder adds a penalty that discourages the encoder representation from changing too sharply when the input changes slightly. This encourages locally stable features.

Conceptually, it penalises sensitivity of the latent representation to input perturbations, often expressed using a Jacobian norm.

8. Predictive Sparse Decomposition

Predictive Sparse Decomposition combines ideas from sparse coding and learned inference: a model predicts sparse representations efficiently while aiming to match representations that explain the input.

Study the precise algorithm and objective from Textbook 3, Chapter 14, as implementations and notation can vary.

9. Applications of Autoencoders

Common applications include dimensionality reduction, denoising, representation learning, compression research, anomaly detection and data generation (for probabilistic variants). Anomaly detection often relies on reconstruction error, but thresholding must be validated on representative data.

1. CNN for recognition

A CNN extracts spatial features using convolutional layers. Image classification predicts a category for an image; object detection predicts categories and locations (usually bounding boxes) for multiple objects.

2. CUDA acceleration

CUDA allows software to use NVIDIA GPUs for parallel computation. Convolution and pooling workloads involve many numerical operations. Efficient kernels, memory access and batching can improve throughput, but actual speed depends on hardware, model shape and implementation.

3. TensorRT optimization

NVIDIA TensorRT is an inference optimization and runtime technology. It can optimize supported models and use precision modes and hardware-specific tactics to improve latency or throughput. Validate accuracy after optimization and measure on the target device.

Evaluation checklist

  • Task metrics: classification accuracy or precision/recall; detection metrics such as mAP.
  • Performance: latency, throughput, memory use and power where relevant.
  • Deployment: target hardware, input sizes, batch size and preprocessing consistency.
  • Reliability: test varied lighting, viewpoints, occlusion and unfamiliar examples.
Key lesson: a model is not “real-time” just because it uses a GPU. Measure end-to-end latency, including preprocessing, inference and postprocessing.
